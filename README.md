# Симулятор автобусных маршрутов Оренбурга

Streamlit-приложение загружает маршруты и остановки из OpenStreetMap. В симуляции можно менять число и вместимость автобусов, часы работы и интенсивность пассажиропотока. На карте видны автобусы и очереди на остановках. Журнал и итоговую сводку можно выгрузить в Excel.

## Запуск

```bash
python -m pip install streamlit pandas numpy matplotlib folium streamlit-folium requests xlsxwriter
streamlit run main.py
```

Модель предназначена для сравнения сценариев по заданным параметрам. Для загрузки маршрутов требуется доступ к Overpass API.
