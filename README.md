# Imitation — имитация пассажирских маршрутов Оренбурга

Интерактивное веб-приложение на **Streamlit** для имитационного моделирования работы городского пассажирского транспорта (автобусы/маршрутки) Оренбурга. Реальные маршруты и остановки подгружаются из **OpenStreetMap** (Overpass API), после чего запускается пошаговая симуляция движения автобусов, накопления очередей пассажиров на остановках и выручки перевозчика.

## Возможности

- **Реальные маршруты из OSM** — автоматическая загрузка автобусных маршрутов и маршруток Оренбурга (`route=bus`, `route=share_taxi`) через Overpass API, включая координаты остановок.
- **Настраиваемая симуляция** через боковую панель:
  - выбор маршрута;
  - количество автобусов и вместимость (мест);
  - время начала/окончания движения;
  - порог "проблемной" остановки (по размеру очереди);
  - интенсивность прихода пассажиров отдельно для дневного времени и часа-пик;
  - выбор часов пик;
  - скорость и режим анимации (пошагово / авто / до конца).
- **Интерактивная карта** (Folium) с положением автобусов, остановками и подсветкой проблемных остановок (большая очередь).
- **Метрики в реальном времени**: обслужено пассажиров, пассажиров на остановках, количество проблемных остановок, доход, средняя загрузка автобусов, средняя очередь, среднее время ожидания.
- **Аналитика и графики** (Matplotlib): накопительный доход, динамика очередей, загрузка автобусов, свободные места и др.
- **Экспорт результатов** — выгрузка полного лога симуляции и итоговой сводки в Excel (`.xlsx`).

## Стек

- Python 3
- [Streamlit](https://streamlit.io/) — веб-интерфейс
- [Folium](https://python-visualization.github.io/folium/) + [streamlit-folium](https://github.com/randyzwitch/streamlit-folium) — интерактивная карта
- [Overpass API](https://wiki.openstreetmap.org/wiki/Overpass_API) — данные маршрутов из OpenStreetMap
- pandas, numpy, matplotlib — обработка данных и графики
- XlsxWriter — экспорт в Excel

## Установка

```bash
git clone https://github.com/xishe/Imitation.git
cd Imitation
pip install streamlit pandas numpy matplotlib folium streamlit-folium requests xlsxwriter
```

## Запуск

```bash
streamlit run main.py
```

После запуска приложение откроется в браузере (по умолчанию `http://localhost:8501`). При первом старте потребуется подключение к интернету — идёт запрос к Overpass API для получения актуальных маршрутов Оренбурга.

## Как пользоваться

1. Дождитесь загрузки маршрутов из OpenStreetMap.
2. В боковой панели выберите маршрут и настройте параметры симуляции (число автобусов, вместимость, время работы, интенсивность пассажиропотока, часы пик).
3. Нажмите **▶ Новый запуск**, чтобы инициализировать симуляцию.
4. Управляйте прогоном:
   - **Следующий шаг** — один шаг вручную;
   - **Имитация до конца (моментально)** — прогнать всю симуляцию сразу;
   - **Авто-анимация** — непрерывное пошаговое воспроизведение с заданной скоростью;
   - **■ Стоп** — остановить.
5. Следите за картой, метриками и таблицами по автобусам/остановкам.
6. Нажмите **Обновить графики/аналитику**, чтобы построить графики и получить итоговую сводку.
7. Скачайте лог симуляции и сводку в Excel через кнопку **Скачать лог симуляции**.

## Примечания

- Overpass API — публичный сервис, может быть медленным или временно недоступным; в этом случае загрузка маршрутов завершится ошибкой, стоит повторить попытку позже.
- Логика симуляции упрощённая (случайное появление пассажиров по заданным интервалам, движение автобусов по кольцу остановок) и предназначена для демонстрации/анализа сценариев, а не для точного моделирования реального трафика.
